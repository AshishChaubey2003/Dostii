# Prompt Sheet - AI Tools Used

## All Exact Prompts Used to Generate This Ad

---

## 1. SCRIPT GENERATION - Groq (LLaMA 3)

**Tool:** Groq API (llama3-70b-8192)
**Purpose:** Generate Hindi/Hinglish video script

**System Prompt:**
```
You are a Hindi ad copywriter for an Indian app called Dostii.
Dostii connects lonely men with female companions for voice chat.
Write emotionally resonant scripts in Hindi/Hinglish.
Target audience: long-haul truck drivers, age 28-40, rural India.
Keep language simple, like how a truck driver talks.
```

**User Prompt:**
```
Write a 35-second video ad script for Dostii app targeting truck drivers.
Include: Hook showing loneliness at 2AM on highway, pain of no one picking up
calls, relief moment when Dostii female friend answers, CTA to download.
Use Hindi. Timestamps karo har scene ke liye.
```

---

## 2. VIDEO SCENES - Pika Labs

**Tool:** Pika Labs (pika.art) - Free tier
**Purpose:** Generate AI video clips for each scene

**Scene 1 Prompt (Hook):**
```
Night highway in India, truck driving on empty road, 1:47 AM shown on dashboard,
headlights cutting through dark, lonely atmosphere, cinematic shot from inside
truck cab, warm dashboard glow, photorealistic, 4K
```

**Scene 2 Prompt (Pain):**
```
Indian truck driver sitting alone at roadside dhaba at night, holding phone,
sad expression, "call busy" notification on screen, dim yellow dhaba lights,
flies around bulb, chai glass on table, realistic Indian setting
```

**Scene 3 Prompt (Dostii Moment):**
```
Indian truck driver inside truck cab at night, smiling while talking on phone,
warm golden light filling the cab, relief on face, phone screen showing chat
app, close up on face changing from sad to happy, cinematic
```

**Scene 4 Prompt (CTA):**
```
Dostii app logo on phone screen, Play Store download button visible, highway
lights in background blurred bokeh effect, clean minimal shot, smartphone
held up, Indian night highway background
```

---

## 3. VOICEOVER - ElevenLabs

**Tool:** ElevenLabs (elevenlabs.io) - Free tier
**Purpose:** Hindi voiceover for male and female voices

**Male Voice Settings:**
```
Voice: Aria (deepened) or custom Hindi male
Stability: 0.65
Similarity: 0.80
Style: Tired, emotional, relatable
Language: Hindi
```

**Male Voiceover Text:**
```
Raat ke 2 baj rahe hain. Sadak lambi hai, aur chuppi aur bhi lambi.
Ghar call kiya... busy tha. Doston ko message kiya... koi jawab nahi.
Phir wahi akela pan. [pause] Yaar... bahut thak gaya tha. Par ab theek lag raha hai.
Chuppi tod. Dostii download karo. Kyunki har raat ek dost chahiye.
```

**Female Voice Settings:**
```
Voice: Warm Indian female, caring tone
Stability: 0.70
Similarity: 0.85
Style: Friendly, warm, genuine
```

**Female Voiceover Text:**
```
Haan bolo Raju bhai... kaisi rahi aaj ki drive?
```

---

## 4. BACKGROUND MUSIC - Suno AI

**Tool:** Suno AI (suno.com) - Free tier
**Purpose:** Background music for the ad

**Music Prompt:**
```
Sad slow Hindi instrumental, highway night mood, acoustic guitar, light tabla,
melancholic but hopeful ending, no lyrics, 40 seconds, Bollywood style,
fades from sad to warm/hopeful in last 10 seconds
```

---

## 5. FINAL EDITING - CapCut

**Tool:** CapCut (capcut.com) - Free
**Purpose:** Combine all clips, voice, music into final video

**Editing Steps:**
```
1. Import all 4 video clips from Pika Labs
2. Arrange in order: Scene 1 > 2 > 3 > 4
3. Add male voiceover track
4. Add female voiceover at Scene 3 timestamp (0:15)
5. Add Suno background music, volume 30%
6. Add Hindi text overlays at each scene
7. Add Dostii logo at end (0:28)
8. Export as MP4, 1080p, 35 seconds
```
