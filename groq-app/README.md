# Groq App - Dostii Ad Generator

## Kya Karta Hai Ye App?

Groq AI use karke automatically generate karta hai:
- Hindi ad script (35 seconds)
- Pika Labs video prompts
- ElevenLabs voiceover text
- Suno AI music prompt

## Kaise Run Kare?

1. index.html browser mein open karo (double click)
2. console.groq.com pe free account banao
3. API Keys section mein jaake key copy karo
4. App mein API key paste karo
5. Persona select karo
6. "Generate" button dabao

## Files

- index.html → Main UI
- app.js     → Groq API logic

## Free Hai? Haan!

Groq ka free tier daily limit mein kaafi hai is project ke liye.
