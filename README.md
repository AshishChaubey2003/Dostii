# 🎬 Dostii — AI Video Ad Campaign

> AI-powered video advertisement campaign built entirely using free Generative AI tools.

---

## 📌 Assignment Overview

This project is a complete AI-generated video ad campaign for **Dostii** — an app that connects lonely individuals with female companions for meaningful conversations.

The campaign targets **Long-Haul Truck Drivers** (Blue-Collar Voyager persona) — one of India's most isolated workforces.

## 🚀 Groq App — AI Script Generator

A web app that auto-generates Hindi ad scripts and video prompts using Groq API.

### How to Run
1. Open `groq-app/index.html` in browser
2. Get free API key from [console.groq.com](https://console.groq.com)
3. Select persona
4. Click **Generate Script + Prompts**

## 📊 Strategy Highlights

### A/B Test Variations
- **V1** — Funny hook instead of sad hook
- **V2** — Energetic female voice instead of soft voice
- **V3** — Haryanvi folk music instead of Hindi instrumental

### Key Metrics (First 7 Days)
- CTR target: 2–4%
- Install Rate target: 15–25%
- Cost Per Install target: ₹20–₹40
- Day 1 Retention target: 40%+

### CAC Optimization
- 6-second bumper ads instead of 15-second
- Moj/Josh platform instead of YouTube
- Night-only targeting (9 PM – 2 AM)
- Hyper-specific hook ("NH-44 pe akele ho?")
